## 本版实际改动

- 新项目模板继续使用 `capability_resolution_policy=discover_then_prepare_if_permitted`；旧项目未声明时不强制迁移。
- MCP 适配采用 discover → reuse → license check → prepare-if-permitted → smoke-test → register → fallback。
- “免费”不再作为自动安装的充分条件；代码、模型权重、模型卡资源与第三方资产分别核查许可证是否允许当前用途。
- `separate_dialogue` 可使用 Demucs 兼容本地实现；Demucs 代码为 MIT 许可的可选实现。预训练权重单独核查，Release 不随包分发第三方模型权重；商业许可不明确时不静默用于商业流程。
- Demucs / PyTorch 等大下载或会改变 Python 环境的依赖，先说明影响，默认安装到项目独立 venv，不修改用户已有全局 Python。
- `music_direction_ref` 存在即启用 Music Mode Gate；缺少 `music_direction_policy` 不再形成绕过路径。确认后直接修改采用的 Music Map 会使旧授权失效。
- `examples/synthetic-ready` 迁入已确认的 `narrative_led` Music Direction；中英 README 补 Direct 2 与 Execute 两个提问示例。
