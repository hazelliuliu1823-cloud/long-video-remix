## 验证边界

自动化可以证明 Visual Gate 状态、文件存在与身份、capability-map 的工具 / entrypoint 声明、授权指纹和合成执行链的一致性。它不能单独证明某张 proof 真的由声明的 renderer 生成，也不能证明视觉审美或真实长视频播放效果。最终 proof 复现和成片观感仍需实际运行 / 观看确认。

本版没有真实长视频端到端 mockup → proof → final render 实测。
