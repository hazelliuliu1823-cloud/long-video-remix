# v1.2.0 范围与验证记录

2026年10月8日。在 v1.1.0（第二轮审阅修复版）基础上增加视觉交付；本记录同时覆盖对上传 v1.2.0（SHA-256 `c4061e688a693b87…`）的审阅修复。

## 本版范围

1. Detail 单独保存并交付核心关键帧原图，连同清单与 handoff 交给 Direct 2。
2. Direct 2 用真实关键帧做一两个 mockup **锁定全片风格**，随执行包交付字体、版式参数、必要资源与可复用生成入口。
3. Execute 沿用同一套设计；QA 核对成片与 mockup 风格是否匹配。
