## 限制

- 尚未在真实长视频上做 benchmark，读图量与耗时的改善未经证实。
- signals 的阈值是合成素材上的默认值，需要用真实素材校准；远景中的细小动作可能低于阈值，靠核心范围 1fps 下限、Broad 动作候选和对白兜底。
- `confirmed_by` 只是声明，机器无法核实确认人。
- 已做 Python 3.9 语法兼容检查，未在 3.9 解释器上实际运行。
