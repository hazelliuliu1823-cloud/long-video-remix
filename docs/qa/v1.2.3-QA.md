# v1.2.3 范围与验证记录

日期：2026-10-17

## 本轮范围

本版只调整 Detail → Direct 2 → Execute 的声音精校时机，不增加新的创意阶段或 Audio Gate：

1. Detail 默认 subtitle + waveform / signals first；完整候选区间 ASR 不再是完成条件，只对会改变叙事判断的局部窗口核听 / ASR。
2. 候选 `edit-boundaries.csv` 可用 `boundary_status=partial` 交 selection-ready 保守边界；未被 D2 选中的候选不要求补成最终态。
3. Direct 2 负责选择片段、planned range / boundary ref 与允许校准范围，可在其他模型 / 会话完成。
4. Execute 增加内部 Step 0 — Selected Range Verification：只回看 D2 入选片段 + handles，精校真实 A/V in/out、句尾、停顿、尾音 / 反应和必要 J/L-cut，并把入选 boundary 升为 `supported`。语义冲突返回 D2，Execute 不自行换段。
5. 新项目 schema 升到 1.8；`ready_for_render` 对入选 boundary=`supported` 形成硬门槛。schema 1.7 保留 v1.2.2 的兼容行为。
6. 最终 execution authorization 在 Step 0 后按真实采用范围准备 / 确认。Visual Gate 与 Toolchain Continuity 不变。

## 验证边界

本版机械校验可以保证 schema 1.8 正式渲染前，D2 入选的 boundary 已从 selection-ready 状态升级为 `supported`，并继续执行既有 evidence / dialogue / authorization / Visual Gate 约束。它不能证明真实长视频上的速度提升比例，也不能替代实际原声听辨质量或最终剪辑观感。

本版未做真实长视频端到端性能 benchmark；“减少 Detail 全量 ASR”的收益仍需在真实项目中记录候选音频跨度、定向 ASR 秒数和 Step 0 最终核验秒数后评估。
